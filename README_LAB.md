# VPS SOC Analyzer - работа на Python

Добро пожаловать в репозиторий лабораторной работы по разработке модульного инструмента автоматизации информационной безопасности (мини-SOC) для VPS-сервера!

В рамках  работы: написание сетевых утилит до парсинга реальных логов угроз, оценка уровня риска сервера, контроль целостности его конфигурации и публикации своего проекта на GitHub по стандартам разработки (GitHub Flow).

---

## 🎯 Цели и задачи работы

Вам предстоит реализовать набор функций в модуле `vps_soc_analyzer.py` и интегрировать их в общую цепочку анализа (Pipeline) в файле `vps_soc_main.py`.

### 🛠️ Что нужно реализовать:
1. **Парсинг логов SSH (`extract_ip`)**: Извлечение IP-адресов злоумышленников из строк о неудавшихся попытках входа.
2. **Агрегацию атак (`group_by_ip`)**: Подсчет количества атак по каждому IP-адресу с помощью словарей.
3. **Детектор Brute-Force (`detect_brute_force`)**: Выявление IP-адресов, превысивших заданный порог атак.
4. **Анализ веб-логов Nginx (`detect_suspicious_paths`)**: Поиск следов веб-сканирования (LFI, обход путей, поиск `.env`).
5. **Оценку уровня рисков (`calculate_risk_score`)**: Вычисление балла опасности и выставление статуса (`LOW`, `MEDIUM`, `HIGH`).
6. **Сетевой сканер портов (`is_port_open`)**: Написание сокетного детектора открытых TCP-портов.
7. **Контроль целостности файлов (`get_file_hash`)**: Вычисление SHA-256 хеш-суммы для системных конфигураций.

## 📂 Структура проекта

Ваш проект на GitHub должен содержать следующие файлы:
* `vps_soc_analyzer.py` — основной модуль, в котором вы реализуете логику анализаторов (замените `pass` в шаблоне на работающий код).
* `vps_soc_main.py` — управляющий конвейер (Pipeline). Вам нужно раскомментировать вызовы разработанных функций в соответствующих шагах.
* `test_vps_soc.py` — набор модульных тестов (`unittest`) для автоматической проверки вашего кода.
* `vps_log_generator.py` — скрипт генерации искусственных логов (не подлежит изменению).
* `requirements.txt` — зависимости проекта.
* `README.md` — документация к вашему проекту.

### Шаг 3. Разработка функций аналитика
Откройте проект в вашей любимой среде разработки (VS Code, PyCharm, IDLE) и реализуйте пустые функции в файле `vps_soc_analyzer.py`, ориентируясь на подсказки и документацию внутри функций.

### Шаг 4. Настройка конвейера
Откройте файл `vps_soc_main.py` и раскомментируйте строки вызовов ваших функций на Шагах 2, 3, 4, 5 и 6, чтобы интегрировать их в общую логику обработки.

### Шаг 5. Модульное тестирование
Перед деплоем кода на реальный сервер, запустите модульные тесты на вашем компьютере:
```bash
python -m unittest test_vps_soc.py
```
Все тесты должны завершиться со статусом **`OK`**. Если какой-то тест выдает `FAIL` или `ERROR`, исправьте ошибку в вашем коде.
